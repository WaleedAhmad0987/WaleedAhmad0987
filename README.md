#### What I work on

- **LLM evals.** LLM-as-judge with deterministic rubrics, semantic grading and behaviour drift checks.
- **Agent end-to-end tests.** Multi-turn conversations, tool calls and the actions an agent takes, asserted field by field.
- **Voice agents.** Real calls, transcripts and what landed in the CRM afterwards.
- **Quality systems from zero.** Risk map, framework, CI gates, production triage and fix verification.
